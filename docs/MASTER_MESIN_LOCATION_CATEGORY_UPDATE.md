# Pembaruan Kategori Lokasi Master Mesin

Kategori Lokasi pada form tambah/edit, filter, API metadata, validasi payload, upload Excel/CSV, template XLSX, dan CHECK constraint SQL Server telah disamakan dengan daftar resmi terbaru sebanyak 47 kategori.

Kategori tambahan yang kini diterima antara lain BIKE THRU, BRI AGRO, DRIVE THRU, GTI, KANINS, KANWIL, KLINIK, PABRIK, PANGKALAN MILITER, PELABUHAN, PERKEBUNAN, PERTAMBANGAN, RUMAH MAKAN, TEMPAT IBADAH, dan TERMINAL.

Migration baru: `020-sync-master-mesin-location-categories.sql`.
